# Capturas de las vistas

Cada pantalla de NextLeague con los datos de prueba (`database/06_datos_prueba.sql`). Las saca Cypress con `npm run capturas`, que vuelve a crear la base de pruebas con esos datos y recorre las vistas como visitante, participante, organizador y administrador.
